# 🌿 TERMITEX
### An Interactive Biomimetic Architecture Lab Inspired by Termite Mounds

**TERMITEX** is an experimental, browser-based 3D project exploring how termite-mound-inspired structures can help us investigate nature-inspired architectural concepts through interactive visualization.

The project combines biomimicry, procedural 3D modeling, web technologies, and experimental hand-tracking interaction to make scientific ideas more tangible and engaging.

> **Project philosophy:** Don't just observe nature. Explore its design principles and experiment with ideas inspired by them.

## ✨ Features

- **Interactive 3D Environment:** Explore and rotate a procedurally generated termite-mound-inspired structure.
- **Adjustable Design Parameters:** Modify parameters such as structure height, base width, and passage density.
- **Conceptual Airflow Visualization:** Animated particles illustrate hypothetical pathways through the passage network.
- **Experimental Hand Tracking:** MediaPipe-based hand-landmark detection can enable gesture-based interaction.
- **Browser-Based Experience:** Explore the prototype using a compatible modern web browser.

*Feature availability may vary by version. Check the current implementation before relying on individual controls.*

## 🛠️ Technology Stack

- **HTML5, CSS3, JavaScript** — web interface and application logic
- **Three.js** — interactive 3D graphics
- **WebGL** — browser-based graphics rendering
- **MediaPipe Tasks Vision** — experimental hand-landmark detection
- **AI-Assisted Development (Vibe Coding)** — an iterative approach to prototyping and development

## 🔬 How It Works

The main visualization pipeline follows this conceptual workflow:

1. User adjusts the design parameters.
2. JavaScript updates the procedural 3D geometry.
3. The structure and passage network are rendered in the browser.
4. Animated particles illustrate hypothetical movement through the structure.
5. Optional hand-tracking input can provide an alternative interaction method.

## 🧪 Scientific Scope and Limitations

TERMITEX is an **experimental biomimicry prototype**, not a validated engineering simulation.

- The generated geometry is inspired by termite-mound architecture; it is not a reconstruction of a specific biological mound.
- The particle animation is illustrative and does not represent validated computational fluid dynamics (CFD).
- Thermal regulation, energy efficiency, and structural performance have not been established by the visualization alone.
- Gesture interaction depends on browser compatibility, camera permissions, and the availability of required external resources.

These limitations define opportunities for future development and scientific validation.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project’s HTML file in a modern browser.
3. If camera-based interaction requires a secure context, run the project through `localhost` or deploy it using HTTPS.
4. Allow camera access when prompted, if hand tracking is implemented and you wish to use it.

**Note:** The project may load Three.js, MediaPipe, or model resources from external CDNs. An internet connection may therefore be required. Check the source code for the exact dependencies and setup requirements.

## 🌱 Why TERMITEX?

Nature offers examples of complex systems shaped by environmental constraints and biological processes. TERMITEX explores how interactive digital tools can help people investigate these systems and generate questions for nature-inspired design.

The long-term goal is to connect **biomimicry, computational design, and interactive scientific exploration**.
